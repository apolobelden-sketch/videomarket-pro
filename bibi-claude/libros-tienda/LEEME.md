## Cómo recuperar los archivos

Por este canal solo se pueden subir archivos de texto, así que los PDF y JPG
van en base64 con extensión `.b64`. Para recuperar cada archivo, en tu
entorno corre:

```bash
base64 -d archivo.pdf.b64 > archivo.pdf
base64 -d archivo.jpg.b64 > archivo.jpg
```

Ejemplo:

```bash
base64 -d libro-2-mis-primeras-palabras-y-frases.pdf.b64 > libro-2-mis-primeras-palabras-y-frases.pdf
```
